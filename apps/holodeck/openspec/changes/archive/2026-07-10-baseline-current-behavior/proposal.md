# Baseline Current Behavior
## Why
Holodeck has working collection, API, and dashboard behavior but no OpenSpec baseline. This change records the current observable behavior so future work can propose changes against a shared contract.
## What Changes
- Capture the current collector CLI, snapshot shape, layer inventories, FastAPI routes, dashboard rendering, and local UI interactions in one `app` capability.
- Archive the baseline so the living spec represents the app as implemented today.
- Keep future intent outside the spec baseline and seed it into `ROADMAP.md`.
## Non-goals
- No code behavior changes.
- No roadmap items or aspirational behavior in the baseline requirements.
- No split into multiple OpenSpec capabilities while the app remains S1-dev.
