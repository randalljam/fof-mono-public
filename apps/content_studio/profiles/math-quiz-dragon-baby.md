Consumer app: **Dragon Fluency Game** (`apps/math-quiz/dragon/` on branch
`feature/math-quiz-dragon-baby`). Source docs on that branch: `dragon/README.md`,

delivering them into the game when that branch is checked out.


## Game context (what the assets support)

3D browser game (Three.js, ES modules, no build step): kid explores a dragon nest, answers
addition bursts to feed the egg, hatches and names a baby dragon, unlocks growth milestones
(wings 70%, flight 100%), follows story stones through meadow/hills. Cute purple baby dragon,
aimed at an eight-year-old. Fluency progress comes from the shared math-quiz SQLite file.

**Runtime dragon today:** procedural mesh in `world/dragon.js` (purple baby, stubby wings,
procedural wing-flap / tail-wag / walk-bob / breathing idle). A rigged GLB replaces it only when
`assets/models/dragon.glb` has animation clips.


## What the game expects (from `ASSETS.md` + `world/dragon.js`)

### 3D model — primary in-world character

| Field | Requirement |
|-------|-------------|
| Path | `apps/math-quiz/dragon/assets/models/dragon.glb` |
| Format | glTF 2.0 binary (`.glb`), rigged with skeletal clips |
| Look | Cute baby dragon — **pink** body (matches the Pipa reference image; supersedes the older purple/lavender spec), warm belly, small horns, expressive purple eyes; appealing to a young child |
| Scale | Game scales GLB at `0.015` on load; model should read well at ~0.5–1.0 unit dragon height in scene space (pipeline normalizes to 45 GLB units tall) |
| Clips (names matched case-insensitively) | `idle`, `walk`, `fly`, `wing-stretch`, `play`, `jump`, `fire`, `hatch` |
| Notes | Unanimated statues are ignored; procedural fallback stays until a rigged GLB ships. **Generated by `apps/content_studio/model3d/`** (image → Hyper3D Rodin mesh → Blender scripted rig/clips → GLB): `python -m apps.content_studio.model3d.cli build --image <ref> --out <glb>`. |

### Growth stages (delivered 2026-07-11)

Three life stages, same clip set and contract, sized 1x/2x/4x (GLB bbox height; game scale 0.015):

| Stage | Reference (identity + Rodin input) | GLB (approved/ + game `assets/models/`) | Height |
|-------|------------------------------------|------------------------------------------|--------|
| Baby | `reference/pipa-clean.png` (from provided art) | `dragon.glb` | 45 units (~0.68 scene) |
| Juvenile | `reference/pipa-juvenile.png` (gpt-image-1 edit of baby) | `dragon-juvenile.glb` | 90 units (~1.35 scene) |
| Adult | `reference/pipa-adult.png` (gpt-image-1 edit of baby) | `dragon-adult.glb` | 180 units (~2.7 scene) |

Build command per stage (mesh cached; `--height-units` drives size + validation bounds):
```bash
.venv/bin/python -m apps.content_studio.model3d.cli build \
  --image .../reference/pipa-juvenile.png --out .../dragon-juvenile.glb --height-units 90
```
Style intent for older stages: still cute/sparkly for a young girl — bigger and more graceful,
never fierce. The game only auto-loads `dragon.glb` today; juvenile/adult are staged for the
growth system to wire up.

### Audio — UI and ambience

| Path | Format | Source today | Content Studio role |
|------|--------|--------------|---------------------|
| `assets/audio/click1.ogg` | OGG | Kenney UI Audio CC0 | Optional regen; game synth-fallback exists |
| `assets/audio/confirmation_001.ogg` | OGG | Kenney | Correct-answer chime |
| `assets/audio/drop_001.ogg` | OGG | Kenney | Soft wrong-answer |
| `assets/audio/music_loop.ogg` | OGG | Optional CC-BY track | **Generate** cozy loop via `audio --kind music`; convert MP3→OGG before delivery |
| *(synthesized)* | Web Audio | `audio/audio.js` | Hatch / milestone / wing-flap tones if OGG absent |

Game loads OGG via `fetch` + `decodeAudioData`. Content Studio outputs **MP3** by default —
convert approved audio to OGG (e.g. `ffmpeg -i in.mp3 -c:a libvorbis out.ogg`) before copying
into `assets/audio/`.

### A. Reference still (required first)

The identity anchor is the Pipa image (pink baby dragon with star wand):
`_data/profiles/math-quiz-dragon-baby/pipa-original-image.png` (as provided), with a
border-cropped copy for generation input at
`_data/profiles/math-quiz-dragon-baby/reference/pipa-clean.png`.

Use as `--image` for every image-to-video / image-to-animation request so the verifier checks
identity preservation.


### B. Short 2D animation loops (GIF) — hatch, idle, wing-flap previews

Good for story overlays, loading screens, milestone cards, or art-direction references until a
rigged GLB exists. Game does **not** load these for the 3D dragon yet — deliver to
`assets/cinematics/` or `assets/reference/` on the dragon branch.

| Asset id | Prompt (starting point) | Duration | Out (staging) |
|----------|-------------------------|----------|---------------|
| `idle-loop` | the baby dragon breathes gently and blinks, subtle tail sway, cozy nest lighting | 2s | `staging/idle-loop.gif` |
| `wing-flap` | the baby dragon slowly flaps its small wings, proud and cute, no extra limbs | 2s | `staging/wing-flap.gif` |
| `hatch-burst` | the baby dragon cracks out of the egg and looks around happily, one clean dragon only | 2.5s | `staging/hatch-burst.gif` |
| `fire-play` | the baby dragon puffs a tiny playful flame and wiggles with delight | 2s | `staging/fire-play.gif` |

Example command:

```bash
.venv/bin/python -m apps.content_studio.cli animate \
  --image apps/content_studio/_data/profiles/math-quiz-dragon-baby/reference/baby-dragon.png \
  --prompt "the baby dragon gently flaps its small wings and blinks, cozy and cute" \
  --duration 2 --fps 12 \
  --out apps/content_studio/_data/profiles/math-quiz-dragon-baby/staging/wing-flap.gif
```

Verifier flags: extra limbs, identity drift, melted anatomy — regenerate until pass, then move to
`approved/`.

## Visual style constraints (pass to every prompt)

- **Character:** single baby dragon, pink body, cream belly, small cream horns, big friendly purple eyes (match the Pipa reference).
- **Tone:** warm, cozy, encouraging — never scary or violent.
- **Motion:** gentle; avoid frantic camera shake or morphing.
- **Negative baseline:** already seeded by Content Studio; verifier adds retry-specific negatives
  (extra limbs, duplicate wings, melted face, identity drift).


## Delivery checklist

1. All visual candidates passed `cli verify` (or `generate_and_verify` in the loop).
2. Approved files sit in `_data/profiles/math-quiz-dragon-baby/approved/`.
3. Audio converted MP3 → OGG where the game expects OGG.
4. On the dragon worktree, copy into `apps/math-quiz/dragon/assets/` (gitignored there — safe).
5. Update `dragon/ASSETS.md` on that branch with provenance when integrating (not this branch).

Shared local files mean step 4 from any worktree sees the same `_LOCAL_FILES` tree once
`apps/math-quiz/dragon/assets/` exists and is populated from approved outputs.


## Out of scope for Content Studio

- Procedural Three.js environment geometry (already in code).
- Kenney UI click/confirm/drop OGGs (already documented with download commands).
