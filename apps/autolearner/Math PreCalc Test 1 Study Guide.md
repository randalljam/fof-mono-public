# Important Things to Remember

## When solving problems:

1.  Always **write down** relevant information and equations; draw a diagram if possible
2.  **Reread the question** and ensure you've interpreted it correctly and have written all the information correctly
3.  Solve. **Double check** each step to ensure no errors.
4.  **Check your answer.** Math, particularly algebra, is very easy to check once done. Plug in real values for your variables and make sure they make sense all the way through.

# Chapter Specifics

## <span style="color: #007fff;">2.1: Quantities and Co-variation of Quantities</span>

### Key Terms

- **Quantity:** A measurable value (time, distance, cost, temperature, etc.)
- **Independent Variable:** Input; causes change.
- **Dependent Variable:** Output; depends on the input.
- **Co-variation:** How two quantities change together.

### Strategy

1.  Identify the two quantities.
2.  Determine which depends on the other.
3.  Describe the relationship:  
    Increase → Increase  
    Increase → Decrease  
    Constant

## <span style="color: #007fff;">2.3: Constant Rate of Change and Linear Formulas</span>

### Important Equations

- Slope
    - $m=\dfrac{y_2-y_1}{x_2-x_1}=\dfrac{\Delta y}{\Delta x}$
- Slope-Intercept Form
    - $y=mx+b$
- Point-Slope Form
    - $y-y_1=m(x-x_1)$

### Strategy

1.  Find the slope using two points.
2.  Solve for $b$.
3.  Write $y=mx+b$.

### Linear Relationship

- Equal changes in $x$ produce equal changes in $y$.

## <span style="color: #007fff;">2.4: Constant Rate of Change and Proportionality</span>

### Equation

$y=kx$

- $k$ = constant of proportionality

### Test for Proportionality

Check whether $\dfrac{y}{x}$ is constant.

### Remember

Proportional:

- Passes through (0,0)
- No y-intercept

Not proportional:

- $y=mx+b,\qquad b\neq0$

Rate equations:

- Always $\dfrac{\text{quantity}}{\text{time}}$

## <span style="color: #007fff;">2.5: Exploring Average Speed</span>

### Formulas

- $d=rt$
    - $r=\dfrac{d}{t}$
    - $t=\dfrac{d}{r}$
- Average Speed

$\boxed{\text{Average Speed}=\frac{\text{Total Distance}}{\text{Total Time}}}$

### Common mistake

**Never average the speeds directly** (unless equal times are spent at each speed).

Always compute separately:

- Total distance
- Total time
- Divide

## <span style="color: #007fff;">3.1: Modeling Function Relationships; the Box Problem</span>

### Volume

- Basic formula
    - $V=lwh$
- Open-top box (box with squares with sidelength $x$ cut out of the corners)
    - $V(x)=x(L-2x)(W-2x)$
    - Domain:
        - $[0,\dfrac{\text{shortest sidelength}}{2}]$

### Strategy

1.  Draw the figure.
2.  Label dimensions.
3.  Determine how each dimension changes.
4.  Write the function.

## <span style="color: #007fff;">3.2: Function Relationships and Domain of Functions</span>

### Function Definition

- Every input has **exactly one output**.
    - *Default:* y is a function of x
        - x is the input
        - Use vertical line test
    - When x is a function of y
        - y is the input
        - Use horizontal line test

### Domain

- All allowable x-values
- "A monarch looks over their (horizontal) domain"
- Common restrictions
    - Denominator:
        - $\text{Cannot equal }0$
    - Square Root:
        - $\text{Inside }\ge0$
    - Context:
        - Dimensions (like in a box) **cannot be negative**.

### Range

- All allowable y-values
- "The (vertical) range of an archer's bow"
- Common range restrictions
    - **Square functions** ($y=x^2$): Outputs can't go below the minimum.
        - Example: $y=x^2$ → **Range:** $y\ge0$
    - **Square root functions** ($y=\sqrt{x}$): Outputs are never negative.
        - **Range:** $y\ge0$
    - **Reciprocal functions** ($y=\frac{1}{x}$): Output can never be 0.
        - **Range:** $y\neq0$
    - **Contextual restrictions:** In modeling problems, outputs must make physical sense.
        - Example: A box's volume cannot be negative, so $V\ge0$.
        - A person's height or distance traveled also cannot be negative.

### Solving function problems

- **When in doubt, graph the function**
    - At the very least, your best approximation on paper

## <span style="color: #007fff;">3.3: Using and Interpreting Function Notation</span>

$y=2x+3$ becomes $f(x)=2x+3$

### Evaluate

Example:

$f(x)=3x-2$  
$f(5)=3(5)-2=13$

### Steps

1.  Replace every $x$ with the given value.
2.  Use parentheses.
3.  Simplify carefully.

**Remember:**

$f(2)\neq f\times2$

It means **"the value of the function when $x=2$."**

### "Don't find y-intercept" problems

**Steps to solve:**

1. Use whatever y-value they have given you as the new "intercept"
2. Subtract the associated x-value from the x variable in the function

**Example:**

You are given the point $(3,13)$ in a word problem and you have deduced that the slope is $-2$.
Instead of solving for the y-intercept/vertical intercept ($b$), just plug in the values:

$f(x)=-2(x-3)+13$

You're essentially translating the graph (like with a parabola) and then changing the intercept so that the graph remains the same as before. **This only works for linear equations**.
Obviously, if you simplify the function you find the y-intercept:

$f(x)=-2x+19$
