2.1 · Quantities and co-variation of quantities

Quantities & Co-variation

Key terms

Quantity

A measurable value — time, distance, cost, temperature, etc.

Independent variable

Input — it causes change.

Dependent variable

Output — it depends on the input.

Co-variation

How two quantities change together.

Strategy

  • Identify the two quantities.
  • Determine which depends on the other.
  • Describe the relationship: Increase → Increase · Increase → Decrease · Constant.
QUICK CHECK"The temperature of a cooling cup of coffee over time." Which is the independent variable, and how do the quantities co-vary?
Time is independent (input), temperature is dependent. As time increases, temperature decreases: Increase → Decrease.
2.2 · Represent quantities and changes in quantities

Representing Quantities

Know how to move between all four representations of the same relationship.

Words

"Costs $3 per ride plus a $5 entry fee."

Table

Rows of $(x, y)$ pairs — check how $y$ changes per unit of $x$.

Graph

Picture of the relationship — slope and intercept visible at a glance.

Equation

$y = 3x + 5$ — compact and computable.

Ask yourself

What is changing?  ·  Is the change constant?  ·  What do the variables represent?

QUICK CHECKA table shows $x$: 0, 1, 2, 3 and $y$: 5, 8, 11, 14. Give the equation.
$y$ goes up 3 for each step of 1 in $x$ (constant change → linear), and $y=5$ when $x=0$. So $y = 3x + 5$.

Strategy: find the line through two points

  • 1. Find the slope using the two points.
  • 2. Solve for $b$ (plug one point into $y=mx+b$).
  • 3. Write $y=mx+b$.

Linear relationship — the definition

Equal changes in $x$ produce equal changes in $y$. That's what "constant rate of change" means.

QUICK CHECKFind the equation of the line through $(2, 7)$ and $(5, 16)$.
$m = \dfrac{16-7}{5-2} = \dfrac{9}{3} = 3$. Then $7 = 3(2) + b \Rightarrow b = 1$. So $y = 3x + 1$. Check: $3(5)+1 = 16$ ✓
2.4 · Constant rate of change and proportionality

Proportionality

$y = kx$   where $k$ = constant of proportionality

Test for proportionality

Check whether $\dfrac{y}{x}$ is constant for every pair in the table.

Rate equations

Always $\dfrac{\text{quantity}}{\text{time}}$.

Proportional

Passes through $(0,0)$ — no y-intercept. Graph is a line through the origin.

Not proportional

$y = mx + b$ with $b \neq 0$. Still linear, but not proportional.

QUICK CHECKTable: $(2, 5)$, $(4, 10)$, $(6, 15)$. Proportional? If so, what is $k$?
$\frac{5}{2} = 2.5$, $\frac{10}{4} = 2.5$, $\frac{15}{6} = 2.5$ — constant ratio, so yes: proportional with $k = 2.5$, i.e. $y = 2.5x$.
2.5 · Exploring average speed

Average Speed

Distance – rate – time

$d = \ ?$   (and solve for $r$, $t$)
$d=rt \quad\Rightarrow\quad r=\dfrac{d}{t}, \quad t=\dfrac{d}{r}$
tap to flip

Average speed

$\text{Average Speed} = \ ?$
$\dfrac{\text{Total Distance}}{\text{Total Time}}$
tap to flip

⚠ The classic trap

Never average the speeds directly (unless equal times are spent at each speed). Always compute separately: total distance, total time — then divide.

QUICK CHECKYou drive 60 miles at 30 mph, then 60 miles at 60 mph. What's your average speed? (Hint: it is not 45.)
Leg 1: $t = \frac{60}{30} = 2$ h. Leg 2: $t = \frac{60}{60} = 1$ h. Total: 120 miles in 3 hours → $\frac{120}{3} = 40$ mph. The slow leg takes longer, so it drags the average below the midpoint.
3.1 · Modeling function relationships

The Box Problem

Volume — basic

$V = \ ?$
$V = lwh$

Open-top box (corners cut out, side $x$)

$V(x) = \ ?$   and the domain?
$V(x)=x(L-2x)(W-2x)$,  domain $\left[0,\ \tfrac{\text{shortest side}}{2}\right]$
tap to flip

Strategy

  • 1. Draw the figure.
  • 2. Label dimensions.
  • 3. Determine how each dimension changes (cutting $x$ from each corner removes $2x$ from length and width; the flap height becomes $x$).
  • 4. Write the function.
QUICK CHECKA 10″ × 8″ sheet has squares of side $x$ cut from each corner and is folded into an open box. Write $V(x)$ and its domain.
$V(x) = x(10-2x)(8-2x)$. Shortest side is 8, so the domain is $[0, 4]$ — cut more than 4″ and the width goes negative.
3.2 · Function relationships and domain of functions

Functions, Domain & Range

Function — the definition

Every input has exactly one output. Default: $y$ is a function of $x$ ($x$ is the input → use the vertical line test). When $x$ is a function of $y$, $y$ is the input → use the horizontal line test.

Domain — all allowable x-values

"A monarch looks over their (horizontal) domain." Common restrictions:

  • Denominator: cannot equal $0$
  • Square root: inside $\ge 0$
  • Context: dimensions (like in a box) cannot be negative

Range — all allowable y-values

"The (vertical) range of an archer's bow." Common restrictions:

  • $y=x^2$: outputs can't go below the minimum → $y \ge 0$
  • $y=\sqrt{x}$: outputs never negative → $y \ge 0$
  • $y=\frac{1}{x}$: output can never be $0$ → $y \neq 0$
  • Context: volume, height, distance can't be negative

When in doubt, graph the function

At the very least, sketch your best approximation on paper — domain and range problems usually become obvious from the picture.

QUICK CHECKGive the domain of $f(x)=\dfrac{\sqrt{x-2}}{x-5}$.
Square root needs $x - 2 \ge 0 \Rightarrow x \ge 2$; denominator needs $x \neq 5$. Domain: $x \ge 2$ and $x \neq 5$, i.e. $[2, 5) \cup (5, \infty)$.
3.3 · Using and interpreting function notation

Function Notation

$y = 2x + 3$ becomes $f(x) = 2x + 3$. Same relationship, better labeling.

Evaluating

Steps

  • 1. Replace every $x$ with the given value.
  • 2. Use parentheses.
  • 3. Simplify carefully.

Example: $f(x) = 3x - 2$, so $f(5) = 3(5) - 2 = 13$.

Remember

$f(2) \neq f \times 2$

It means "the value of the function when $x = 2$."

"Don't find the y-intercept" problems

The shortcut (linear only)

1. Use whatever y-value they gave you as the new "intercept". 2. Subtract the associated x-value from the $x$ in the function.

Given the point $(3, 13)$ and slope $-2$: instead of solving for $b$, write $f(x) = -2(x-3) + 13$. You're translating the graph so it passes through the point — this only works for linear equations. Simplifying reveals the y-intercept anyway: $f(x) = -2x + 19$.

QUICK CHECKA line has slope $4$ and passes through $(2, 9)$. Write it without solving for $b$, then simplify.
$f(x) = 4(x-2) + 9$. Simplified: $f(x) = 4x + 1$. Check: $f(2) = 8 + 1 = 9$ ✓
