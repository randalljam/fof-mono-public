# At-Home Reading Assessment (Age ~7)

This quick-start pack gives you a mastery-based snapshot of core components:
- **Phoneme mastery** (perception & production)
- **Phonics/decoding** across common patterns (real + pseudowords)
- **High-utility irregular ("heart") words**
- **Morphological awareness** (prefixes/suffixes/roots)
- **Oral Reading Fluency (ORF)** and a **Maze** comprehension check

## How to Use (90–120 minutes total, can split across 2–3 days)

1. **Phoneme Mastery (15–20 min)**
   - For each row, say the minimal pair aloud (e.g., *thin* vs *then*). Ask your child: "Do these sound the same or different? Which one has the [target sound]?"
   - Have your child repeat the three probe words. Note substitutions or omissions.
   - Mark "Mastery? Y/N" and add notes.

2. **Phonics/Decoding Probes (20–25 min)**
   - Present items in each pattern; mix real and pseudowords. Stop a pattern after 5 consecutive correct to reduce fatigue.
   - Record errors and target phoneme(s) you suspect (e.g., **/ō/** in *home*).
   - Mastery criterion: ≥95% accuracy within a pattern on untimed reads and ≥90% within 1-second per word when timed.

3. **Heart Words (5–8 min)**
   - Flash each word for ~1 second. If not instant, mark the tricky part ("heart") for study.
   - Aim: ≥90% instant.

4. **Morphology Probe (10–12 min)**
   - Ask for meaning and examples; have your child coin a new word where possible.
   - Aim: can explain ≥70% correctly with examples; by grade 3 target ≥85%.

5. **ORF Passage (5–7 min including scoring)**
   - Have your child read the ORF passage aloud for one minute. Count total words read and subtract errors to compute WCPM (Words Correct Per Minute).
   - Record on the ORF_Log sheet in the workbook.

6. **Maze (5–7 min)**
   - Child silently reads and selects the best word in each bracket.
   - Score = number correct.

## Interpreting Results (rules of thumb, not diagnosis)

- **ORF**: Compare WCPM to norms (see main report for links). Look at accuracy, miscues, and prosody.
- **Phonics**: Any pattern <90–95% suggests review and targeted practice using decodables matched to that pattern.
- **Phoneme Mastery**: Note consistent confusions (e.g., /θ/ vs /ð/, long vowels, r-controlled). Work these in isolation, then in words, then in sentences.
- **Heart Words**: Add non-automatic words to review deck; map irregular part.
- **Morphology**: Strength here can boost vocabulary and multisyllabic decoding.
