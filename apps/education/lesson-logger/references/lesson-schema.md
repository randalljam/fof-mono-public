**Lesson entry schema** — reference for the `lesson-logger` skill.

Based on the saved-entry shape in TL's **academic-logger v2** app
(`tl-user.github.io/academic-logger`), extended with `students` and `teachers` lists (her v2
app logs to a single user; we track who the lesson was for and who taught it). JSON session
files remain close to her entry shape for later import (her localStorage key is
`academicLogger.entries`).

Each field has two tags: **Required** (`REQUIRED` / `OPTIONAL`) and **Source** (`AUTO` =
filled by the save pipeline or channel context; `EXTRACTED` = parsed from the user message by
the extractor; `AUTO/EXTRACTED` = defaults from the sender, overridable if named in the message).


## Entry object (JSON session file)
```json
{
  "id": "f1e2d3c4-...",                       // AUTO — uuid4, generated on save
  "date": "2026-06-06",                        // REQUIRED — extracted — YYYY-MM-DD; defaults to today (America/Los_Angeles)
  "time": "6:30 PM",                           // OPTIONAL — extracted — simple local time in America/Los_Angeles, e.g. "6:30 PM" or "10:15 AM"; default "" when not specified
  "students": ["Kid1"],                        // REQUIRED — extracted — list of names; defaults to ["Kid1"] when none given
  "teachers": ["TL"],                     // REQUIRED — extracted/auto — list of names or ["self"]; defaults to [createdBy] when not mentioned
  "subject": "Math",                           // REQUIRED — extracted — see subjects below
  "curricula": "Singapore Math 4A",            // OPTIONAL — extracted — book, curriculum, or software program
  "duration": 30,                               // REQUIRED — extracted — minutes; positive integer, 1–1440
  "location": "home",                          // OPTIONAL — extracted — free text; where the lesson happened
  "notes": "fractions; did well",              // OPTIONAL — extracted — free text ("" if none)
  "transcript": "Kid1 did 30 minutes of math...", // REQUIRED — auto — verbatim user input (from voice or typed); stored for a self-contained record
  "createdBy": "TL",                      // REQUIRED — auto/extracted — person who logged the lesson; defaults to the Telegram sender (e.g. Randy, TL) unless named in the message
  "createdAt": "2026-06-06T18:00:00-07:00",    // AUTO — ISO 8601, generated on save
  "extractorVersion": "1.0.0"                  // AUTO — version string for the extraction pipeline; generated on save
}
```
`photoDataUrl` (optional, base64 image) exists in her app but is **not** captured over chat.


## Field rules
| Field | Required | Source | Rule |
|-------|----------|--------|------|
| `id` | — | AUTO | uuid4. Generated by `scripts/save_lesson.py` — never hand-write. |
| `date` | REQUIRED | EXTRACTED | `YYYY-MM-DD`; defaults to today (America/Los_Angeles). |
| `time` | OPTIONAL | EXTRACTED | Simple local time in America/Los_Angeles, e.g. `"6:30 PM"` or `"10:15 AM"` (not ISO). Default `""` when not specified — do not guess or fill with the current time. |
| `students` | REQUIRED | EXTRACTED | List of names. **Defaults to `["Kid1"]`** when none is given — confirm in the verify step. Deduped. |
| `teachers` | REQUIRED | EXTRACTED/AUTO | List of names, `["self"]`, or `["not specified"]`. Extractor returns: named person(s) when stated; `["self"]` when clearly self-directed (e.g. student on Khan Academy alone, "on her own"); `["not specified"]` when the transcript doesn't mention a teacher. **Save pipeline resolves `["not specified"]` to `[createdBy]`** (the message sender) when sender is known. The field is never empty in a saved entry. Deduped. Confirm when defaulted. |
| `subject` | REQUIRED | EXTRACTED | One of **Math, Reading, Writing, Art, Science, Music** (case-insensitive). Anything else is kept as a custom subject (with a warning). |
| `curricula` | OPTIONAL | EXTRACTED | Free text: the book, curriculum, or software program used (e.g. `"Charlotte's Web"`, `"Khan Academy"`, `"Singapore Math 4A"`). Default `""`. |
| `duration` | REQUIRED | EXTRACTED | Minutes. Coerced to int. Must be ≥ 1; values > 1440 are clamped (treated as an extraction error). No 5-minute rounding, no 60-min cap. |
| `location` | OPTIONAL | EXTRACTED | Free text — where the lesson happened. Default `""`. |
| `notes` | OPTIONAL | EXTRACTED | Free text; distilled lesson detail. Default `""`. |
| `transcript` | REQUIRED | AUTO | The **full verbatim** user message (voice dictation or typed) that described the lesson. Stored in the JSON file so each record is self-contained. |
| `createdBy` | REQUIRED | AUTO/EXTRACTED | Person who logged the lesson. **Defaults to the Telegram sender** (Hermes knows Randy vs TL from the message channel); override when the message names someone else. |
| `createdAt` | — | AUTO | ISO 8601 timestamp. Generated by `scripts/save_lesson.py` — never hand-write. |
| `extractorVersion` | — | AUTO | Version string identifying the extraction pipeline (e.g. extractor script + schema version). Generated on save — never hand-write. |


## Storage — two layers
- **JSON session files** (human-readable, one per lesson; good for troubleshooting and during
  development): written by `save_lesson.py` to `$HERMES_LESSON_LOG_DIR` or
  `$HERMES_HOME/lesson-logs/`, named `<date>_<subject>_<id8>.json`. Holds **all** fields above.
  These are the safety net — each entry is a self-contained file that can be re-ingested if the
  DB needs to be rebuilt or re-extracted with an improved extractor.
- **SQLite DB** (the queryable layer): `lessons.db` in the same dir (`$HERMES_LESSONS_DB` to
  override). Single `entries` table with all fields. `save_lesson.py` upserts on every save
  (write-through); `lessons_db.py ingest` backfills from JSON files.
  - List fields (`students`, `teachers`) stored as JSON text in their columns. For per-person
    queries, use `json_each`: `SELECT e.date, e.subject FROM entries e, json_each(e.students) WHERE json_each.value = 'Kid1';`
  - `raw_extraction` column holds the LLM's full raw output as JSON (schema-on-read escape
    hatch for experimental fields).
  - `NOT NULL` only on `id`, `date`, `transcript`, `created_at`, `ingested_at` — the rest stays
    permissive while iterating. Required/default logic lives in the application code.
  - WAL mode enabled. Schema version tracked via `PRAGMA user_version`.
  - Re-extraction: overwrite extracted fields in place, bump `extractor_version`; `transcript`,
    `id`, `created_at`, `created_by` are untouched. The preserved transcript + JSON files make
    this reversible.
- Both layers live on the agent's volume (backed up to `[S3-BUCKET]`), **not** in the repo.


## Differences from the project brief / her app
- Her shipped v2 app has **no student field**; we add `students` (REQUIRED, extracted, default
  Kid1) per Randy's decision. Extra key is generally harmless on import.
- We add `time`, `teachers`, `location`, `curricula`, `transcript`, `createdBy`, and
  `extractorVersion` — not in her app; JSON-only extensions for a richer, self-contained session
  record.
- The brief also imagined `subtopic`, `tags`, `follow_up`, `confidence` — deferred until the
  schema is intentionally expanded.
