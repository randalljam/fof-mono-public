## What the report measures

From `repo_status.py`:

| Column | Meaning |
|--------|--------|
| **tracked#** | Files listed by `git ls-files` under that folder that **exist on disk** (symlinks skipped). |
| **tracked MB** | Sum of those files’ byte sizes (`st_size`), shown in **megabytes to one decimal place**. |
| **worktree#** | **Every regular file** under the folder via `os.walk` (directories are not counted; symlinks skipped). |
| **worktree MB** | Sum of **all** those files’ byte sizes, same one-decimal MB format. |

So:

- **Tracked** = “what Git knows about and would ship in a clone/commit.”
- **Worktree** = “what’s actually on disk in that folder right now,” whether or not Git tracks it.

That’s the general split: tracked is Git’s index; worktree is the live filesystem.
